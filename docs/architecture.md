# Architecture

`index.html` loads the browser-ready `dist/app.bundle.v47.js` build. Its source entry point is `src/app.js`, which imports the runtime coordinator in `src/main.js`; configuration, streaming-response cleanup, chat title/memory helpers, storage identifiers, and DOM identifiers are maintained in focused modules under `src/config`, `src/api`, `src/core`, `src/ui`, and `src/utils`.

The browser UI persists chats in IndexedDB and light preferences in localStorage. The user no longer picks a model: on load (and periodically while visible) Umrani probes the three configured text models, picks the FASTEST available one, and hides its real ID behind the single brand label "Umrani 2.2". Requests use that active model and fall back across the remaining models and ten provider accounts if it fails. Chats send the full message history with no context cap. Text and source-code attachments are read in the browser and included as text context; image, PDF and DOCX upload is not exposed. The API helper layer handles cumulative chunks, removes private model-reasoning tags, and prevents repeated rendered blocks. Math (LaTeX) in AI replies is typeset in the browser with KaTeX. After every successful chat reply, the Adsterra Native Banner is inserted inline; closing it is optional and never locks the composer. Only this one native banner format is used (no Social Bar, popunders, or smartlinks). Because this is a static frontend, API keys and client-side logic remain visible to visitors.
